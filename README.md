# Projeto Task Manager
um projeto desenvolvido totalmente em Java para estudo da linguaguem além de ferramentas e frameworks

## Contexto
esse projeto foi usado como atividade para os modulos basico e intermediario da capacitação em Java promovida pelo [IREDE](https://irede.org.br/). Os módulos tiveram objetivos difierentes com assuntos diferentes a serem colocados em prática no codigo, foram eles:

### Módulo Básico
- Interação via terminal
- Estruturas condicionais
- Laços de repetição
- POO
  - Herança
  - Polimorfimos
  - Encapsulamento
- Exceções

### Módulo Intermediário
- Generics
- Javafx 
- Persistencia (JDBC)
- Testes unitários (JUnit)
